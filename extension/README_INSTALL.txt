ИНСТРУКЦИЯ ПО УСТАНОВКЕ РАСШИРЕНИЯ WOLFHUNT PRO (VK + TELEGRAM)
====================================================================

💡 ПОДСКАЗКА ПО VPN:
Плагин отлично работает как с VPN, так и без него.
Но если при подключении ВКонтакте пишет «Flood control» — просто отключите VPN на время авторизации (или добавьте ВК в исключения). С чистого IP домашнего провайдера РФ защита Flood Control исключена на 100%.

БЫСТРАЯ УСТАНОВКА (3 ШАГА):
1. Откройте браузер (Google Chrome, Яндекс Браузер, Edge или Opera).
2. Перейдите по ссылке:
   chrome://extensions/ (для Chrome/Edge) 
   или 
   browser://extensions/ (для Яндекс Браузера)
3. В правом верхнем углу включите тумблер "Режим разработчика" (Developer mode).
4. Нажмите кнопку "Загрузить распакованное расширение" (Load unpacked).
5. Выберите папку:
   D:\downloads\WOLFHUNT_CHROME_EXTENSION

Готово!
Иконка Волка появится на панели расширений (закрепите её булавкой).

Особенности:
- Все запросы идут с вашего реального домашнего IP (0% риска бана по IP, прокси не нужны).
- Истории ВК — строгий Приоритет №1 (3-тактный цикл: Истории -> ДР пачками до 5 (сбор 1 раз в сутки) -> Посты).
- Лимиты безопасности: 300 лайков ВК/день (ночной сон до 00:00 МСК), 150 реакций TG/день.
- Фоновая работа 24/7 прямо в браузере (вкладку сайта можно закрывать).
- Полная двусторонняя синхронизация с сайтом app.greyzzzzwolf.ru.

КАК ОБНОВИТЬ РАСШИРЕНИЕ ДО СВЕЖЕЙ ВЕРСИИ:
1. Скачайте свежий архив: WOLFHUNT_CHROME_EXTENSION.zip
2. Распакуйте его в ту же папку (D:\downloads\WOLFHUNT_CHROME_EXTENSION) с заменой существующих файлов.
3. Откройте в браузере:
   chrome://extensions/ (для Chrome/Edge) или browser://extensions/ (для Яндекс Браузера).
4. Найдите карточку "WolfHunt PRO" и нажмите значок круговой стрелки «Обновить» (или кнопку «Повторить» при запросе).
Готово! Все авторизации, токен и статистика сохраняются полностью.
